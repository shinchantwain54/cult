# 天魔神敎 · The Heavenly Demon Divine Cult

A 3D animated tribute website to the wuxia/murim Demonic Cult, the Demonic Path, and its sovereign, Cheonma, the Heavenly Demon.

- **3D scene** (Three.js): a writhing demonic core, rotating calligraphy rune rings, rising embers, a blood moon and mountain silhouettes, with the camera moving as you scroll
- **Sections:** the Demonic Path, the Divine Cult, the Nine Laws (doctrines), Cheonma, the Demonic Arts, and the Creed
- **Procedural soundtrack** (Web Audio, no audio files): drone, chant, wind, guqin-style plucks and taiko drums that build as you scroll, with a volume slider
- **Blood oath:** spam the button for an escalating combo with blood splatter, screen shake and rising sound

## Run locally

Serve the folder over HTTP (opening the file directly can stop the 3D from loading):

```bash
python -m http.server 5173
```

Then open http://localhost:5173.

All lore on the site is original fan writing in the style of the genre.
